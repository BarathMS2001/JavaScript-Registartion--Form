Registration Form
A responsive Registration Form built with HTML, CSS, and JavaScript. The project demonstrates client-side form validation with separate error messages for each input field.

Features
Name validation

Accepts only letters
Rejects numbers and special characters
Email validation

Accepts only Gmail addresses
Must end with @gmail.com
Password validation

Minimum 6 characters required
Individual field validation

Validation occurs when the user leaves an input field (blur event)
Error messages are displayed separately for each field
Dynamic submit button

Disabled until all fields are valid
Automatically enabled when validation passes
Success message

Displays after successful registration
Clears input fields after submission
Success message disappears when the user starts filling the form again
Technologies Used

JavaScript (Vanilla JS)
